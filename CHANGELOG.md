## [0.1.0] — Initial release

### Added

- Project initialised with Vite + React 18 + TypeScript + Tailwind CSS
- React Router v6 with lazy-loaded routes
- React Hook Form + Zod validation on all entity forms
- In-memory mock API (set `VITE_USE_MOCK=false` to use the real backend)
- Vitest + Testing Library test suite with coverage thresholds
- Dark-mode support via CSS custom properties
- `GlobalErrorBoundary` with resetKey remount
- Sonner toast notifications
